# BSR (Beer Selector & Recommender)

BSR is a mobile application and Go gRPC/Connect-RPC backend for choosing what beer to drink at a bar, pub, or brewery by cross-referencing Untappd venue activity against personal Untappd history. See [INTENT.md](file:///workspaces/bsr/INTENT.md) for the full project architecture and design.

## Development

Follow a standard TDD development process - i.e. write a failing test before adding a feature. Mock out external services to support unit tests.

## Feature completion

Refer to [ISSUES.md](file:///workspaces/bsr/ISSUES.md) for details on the issue processing workflow lifecycle and label transitions.
Once you've finished a change or feature, run the `finish.md` workflow.
